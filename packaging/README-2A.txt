TP C, parcours perso (version portable Windows)
===============================================

À quoi ça sert
--------------
Quatre courtes séances pour apprendre les bases du C avec l'aide d'une IA :
les types et la taille d'un octet, le passage par adresse, les chaînes de
caractères, et un premier sous-programme. Tu écris une fonction, tu cliques
pour compiler et tester, une porte s'ouvre quand c'est juste.

Comment lancer
--------------
1. Décompresse ce dossier où tu veux, par exemple sur le Bureau.
2. Double-clique sur lancer.bat.

Il n'y a rien à installer. Python et le compilateur gcc sont déjà dans le
dossier. Il faut un Windows 64 bits.

Si quelque chose cloche, lance d'abord diagnostic.bat. Il vérifie que gcc,
Python et PyQt6 répondent, et affiche un message clair.

Le tuteur IA
------------
Le bouton d'aide utilise Claude Code, qui s'installe et se connecte à part,
avec ton propre compte. Si Claude Code est présent sur ta machine et que tu
es connecté, le tuteur s'allume tout seul. Sinon, les quatre séances
fonctionnent quand même entièrement, juste sans l'aide de l'IA.

À savoir : il n'existe pas d'essai gratuit de Claude Code. Le plan Pro coûte
20 dollars par mois. Le plan gratuit de Claude n'inclut pas Claude Code.
