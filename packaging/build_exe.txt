Construire le .exe (PyInstaller) — parcours be_c
================================================

Prerequis : un vrai Python 3.12 (pas l'embeddable) avec pyinstaller et pyqt6 :
    python -m pip install pyinstaller pyqt6

1. Dans un dossier de build vide, copier depuis ce depot :
     - tous les *.py de la racine
     - le dossier contenu/be_c/
     - packaging/entree_be_c.py

2. Depuis ce dossier de build :
     python -m PyInstaller --noconfirm --windowed --name TP-C-perso ^
       --add-data "contenu/be_c;contenu/be_c" entree_be_c.py

   Resultat : dist/TP-C-perso/ (TP-C-perso.exe + _internal/).

3. Assembler le livrable : a cote de TP-C-perso.exe et _internal/, placer
     - le dossier w64devkit/ (gcc, extrait de w64devkit-x64-2.8.0.7z.exe)
     - lancer.bat, diagnostic.bat, README.txt (depuis packaging/)

Notes :
  - Le .exe force --parcours be_c (via entree_be_c.py).
  - lancer.bat met w64devkit\bin et claude/codex au PATH puis lance le .exe.
  - Le .exe trouve aussi gcc seul s'il voit w64devkit\ a cote de lui
    (executeur.assurer_compilateur_sur_path), donc il marche meme en double-clic
    direct, sans passer par lancer.bat.
