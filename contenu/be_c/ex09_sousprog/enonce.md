# Exercice 9 — les sous-programmes

Une droite : `y = a*x + b`. Écris une fonction `calcul_ordonnee(a, b, x)` qui
renvoie `a*x + b`.

Dans le `main` : `a = 4`, `b = 3`, `x = 2`, appelle la fonction et affiche `y`
— « pour x = 2.000000 vaut y = 11.000000 ».

But : une fonction qui renvoie une valeur avec `return`.
