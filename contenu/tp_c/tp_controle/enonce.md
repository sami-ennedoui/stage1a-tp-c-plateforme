# Exercice 3, les structures de contrôle

C'est l'exercice 3 du BE. Trois variables sont en place, `a` valant 1.5, `b` valant 0.5 et `c` valant 0.6. Tu réalises un menu avec un `switch ... case` qui permet à l'utilisateur de modifier une de ces variables.

Le programme affiche le menu, lit le choix au clavier, et selon le choix modifie a, b ou c avec une nouvelle valeur saisie. Si le choix n'existe pas, tu affiches un message d'erreur. Après la modification, tu affiches les nouvelles valeurs. Puis, avec une boucle `do ... while`, tu redemandes à l'utilisateur s'il veut modifier autre chose.

La porte fournit une saisie qui modifie `a` avec la valeur 9.9 puis arrête la boucle. Elle vérifie que cette nouvelle valeur apparaît bien dans ta sortie.
